Because this application is not code-signed, Windows Defender (and sometimes SmartScreen) may block it on first launch. This is expected behavior for unsigned applications that access hardware sensors.

To run the application safely, you may need to allow the entire application folder in Windows Defender:

How to allow the folder in Windows Defender:

1.Open Windows Security

2.Go to Virus & threat protection

3.Select Manage settings under Virus & threat protection settings

4.Scroll down to Exclusions

5.Click Add an exclusion → Folder

5.Select the folder where you extracted the application

6.After adding the exclusion, the program will run normally.
